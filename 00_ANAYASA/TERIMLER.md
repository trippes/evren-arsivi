# Terimler Sözlüğü

| Terim | Anlam |
|---|---|
| Kanon | Proje sahibi tarafından onaylanmış evren bilgisi |
| Taslak | Henüz kesinleşmemiş çalışma içeriği |
| Varlık | Karakter, yer, toplum, olay gibi bağımsız kayıt |
| Kayıt kimliği (id) | Bir varlığı diğerlerinden ayıran kalıcı anahtar |
| Çelişki | İki veya daha fazla kaydın aynı konuda uyuşmaması |
| Retcon | Önceden kanon olan bilginin gerekçeli kararla değiştirilmesi |
| Kaynak | Bir bilginin dayandığı belge, karar veya kayıt |

Yeni terimler eklendikçe sözlük güncellenir. Evren içi anlamlar ile proje yönetimi terimleri karıştırılmaz.
