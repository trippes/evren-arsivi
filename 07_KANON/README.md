# Kanon Yönetimi

Bu dizin, onaylanmış bilgilerin indeksini ve henüz çözülmemiş tutarsızlıkları yönetir.

- kanon-indeksi.json: Kanon kayıtlarının merkezi listesi.
- celiskiler.json: Çözülmemiş veya çözülmüş çelişkiler.
- karar-gunlugu.md: Kanon kararlarının gerekçeli geçmişi.

Bir kaydın dosyada bulunması onu otomatik olarak kanon yapmaz. Durumu açıkça kanon olmalıdır.
