# Çalışma Alanı

Bu dizin henüz kanon olmayan fikirleri, alternatifleri, taslak sahneleri ve araştırma notlarını barındırır.

Buradaki hiçbir içerik açık onay ve kanon kaydı olmadan kesin evren bilgisi olarak sunulamaz. Taslaklar gerektiğinde ilgili varlık dosyasına taşınır; kaynak taslak silinmek yerine arşivlenebilir.
